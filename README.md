# Dharshini Ilangovan — Portfolio

A responsive, dependency-free portfolio website built from `index.html`, `styles.css`, and `script.js`.

## Preview locally

Open `index.html` in a modern browser. No build step is required.

## Publish

Upload these three files to any static hosting service, such as GitHub Pages, Netlify, or Vercel. The site has no server-side dependencies.
